# Native Squall LLVM integration — 2026-10-24

Squall instruction selection and assembly now run inside the native LLVM tools.
The C++ target lowers verified LLVM IR directly into token/slot MCInsts through
`TargetMachine::addPassesToEmitFile`, then uses LLVM MC streamers to produce
assembly or ELF. This is a registerless, serial IR-to-MC backend, not a
register-based MachineInstr pipeline. It does not invoke Python or the standalone
compiler/assembler. The built Clang can also emit Squall objects directly.

The Python implementation remains an independent implementation of the same
serial `squall-cell-memory-2` ABI. Python runners unpack already encoded native
objects and orchestrate reference/RTL tests; they do not generate native code.

## Reproduce

Build with `python llvm/utils/squall/build.py --build-dir ../squall-llvm-build
--jobs 6 --check`, with Ninja on PATH. Install the test package as documented in
the build guide, then set `SQUALL_LLVM_BIN`, `SQUALL_CLANG`,
`SQUALL_REFERENCE_DIR`, and `SQUALL_ISACOMP_DIR` to the native bin directory,
built Squall Clang, and pinned source checkouts respectively.

```sh
python -m pytest -q llvm/tools/squall-compiler/tests
python ../squall-llvm-build/bin/llvm-lit -v llvm/test/MC/Squall llvm/test/CodeGen/Squall
python llvm/utils/squall/test_rtl.py \
  --clang ../squall-llvm-build/bin/clang \
  --native-bin ../squall-llvm-build/bin \
  --isacomp-dir ../isacomp-squall-2026-10-20 \
  --include-memory --random-seeds 0 1 7 42 113 2026 --stall-seeds 17 91 \
  --output ../squall-native-regression-2026-10-24
python llvm/utils/squall/audit_native_images.py \
  ../squall-native-regression-2026-10-24 --native-bin ../squall-llvm-build/bin --compare-python
```

Saved local artifacts are in `../squall-native-regression-2026-10-24`: generated
sources/IR, ELF objects, initialized images/manifests, reference/RTL traces,
per-run results, `REPORT.md`, `final-native-audit.json`, and
`independent-compiler-comparison.json`. Adjacent `squall-native-full-suite-2026-10-24`
and `squall-native-build-check-2026-10-24` logs retain package and build checks.

## Scope and remaining work

The native implementation is an initial closed-module image compiler for the
supported integer/pointer/array subset. General byte/struct/heap memory,
external calls/libraries, flat host-pointer interoperability, separate object
linking, new-PM codegen/MIR/JIT, and parallel scheduling remain unimplemented.
ELF machine ID 999 and relocations are experimental project conventions. The
assembler records unresolved relocations; there is no Squall linker to apply
them. Compiler images contain no unresolved references.

The serial runtime mailboxes must be redesigned before memory operations can
overlap. Verification here covers fresh immutable-code launches and does not
establish general RTL correctness or physical tapeout signoff. Public native
CI builds MC/llc and runs lit plus native differential tests; private RTL CI
still needs the access setup described in the compiler README. Hosted CI
results must be checked separately from the local evidence above.
